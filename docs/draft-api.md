# API сценария Alpha

UI и API работают с одного адреса. POST принимает `application/json`. Вход устанавливает подписанную cookie `buddy_session`; бэкенд определяет владельца из сессии. MCP использует тестовый Bearer-токен и один аккаунт Alpha. Исходные роли и команду имитирует Go.

| Метод | Путь | Тело и ответ |
|---|---|---|
| POST | `/api/demo/login` | `{"user_id":"demo-intern-1","password":"alpha-demo-1"}` → тестовый пользователь |
| GET | `/api/session` | Текущий пользователь |
| POST | `/api/demo/logout` | Удаляет cookie |
| POST | `/api/chat` | `{"message":"Как получить доступ?"}` → намерение, ответ, источник или черновик |
| GET | `/api/knowledge/{source}` | Текст разрешённой инструкции |
| POST | `/api/drafts` | `{"resource_id":"team_space","reason":"Нужны инструкции"}` → 201 и черновик |
| GET | `/api/drafts/current` | Текущий черновик или `null` |
| GET | `/api/drafts/{id}` | Свой черновик по ID |
| POST | `/api/drafts/{id}/confirm` | `{"version":1}` → черновик с результатом |

Один стажёр ведёт одну заявку на `team_space`. Повторное создание возвращает ранее сохранённый черновик. POST подтверждения вернёт тот же номер, если результат уже сохранён.

```json
{
  "draft_id": "0123456789abcdef0123456789abcdef",
  "draft_url": "/drafts/0123456789abcdef0123456789abcdef",
  "resource_name": "Вики команды Alpha",
  "reason": "Нужны инструкции",
  "status": "pending_approval",
  "version": 1,
  "request_id": "REQ-0123456789ab",
  "next_step": "Дождись согласования наставником. Пока ждёшь, изучи вводную команды."
}
```

Черновик до подтверждения имеет статус `awaiting_confirmation` и `request_id:null`. Успех отправки означает, что заявка зарегистрирована и ждёт согласования. Бэк не открывает раздел вики.

Ошибки передаются как `{"error":{"code":"draft_not_found","message":"Черновик недоступен по этой ссылке."}}`. Коды HTTP: 400 для неверных данных, 401 без учётки, 403 для команды без прав, 404 для отсутствующего или чужого черновика, 409 для устаревшей версии, 413 для большого тела, 415 для неверного формата, 503 для временной недоступности модели или сервиса заявок.
