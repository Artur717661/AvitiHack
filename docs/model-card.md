# AI-buddy intent router: локальный LoRA-кандидат

Версия эксперимента: train-local-2026-11-14. Назначение: выбор одного из шести намерений стажёра в сценарии доступа к пространству команды. Язык входных примеров — русский.

Основа: Qwen/Qwen3-1.7B, revision 70d244cc86ccca08cf5af4e1e306ecf908b1ad5e. Адаптер: reports/train-local-2026-11-14/adapter-final. Используется вместе с этой основой; сам по себе не является полной моделью. Рецепт и фактические хеши записаны в report.json и inputs.

Вход модели: message и workflow_state. Backend-контекст проверяется по схеме и не включается в prompt. Выход: JSON с единственным полем intent, значение explain_access/request_access/request_status/next_step/clarify/out_of_scope. Использовать строгий parser и явно обрабатывать ошибки/таймауты.

Обучение: LoRA r8, alpha16, q_proj/v_proj, 3 эпохи по 108 train-записям, 81 optimizer step, lr0.0002, microbatch1, accumulation4. Ответ и EOS обучаются, prompt masked. Основа заморожена. Запуск на RTX 4060 Laptop 8 ГБ, BF16, без аренды.

Данные синтетические и ожидают проверки аналитика. Разделение по семействам: train108/dev24/test30. Dev/test по шесть семейств, поэтому перефразы не независимы. Test не использовался в этом эксперименте. Отдельный probe виден разработчикам и используется только для диагностики.

Dev: 15/24 → 22/24, macro-F1 0,5714 → 0,9153, невалидные ответы 2 → 0. Status probe: 8/10 → 10/10; next-step probe: 2/10 → 10/10. На семи известных примерах интеграции 7/7. Подробнее: docs/local-training-result-2026-11-14.md.

Известные ограничения: две ошибки dev; на противоречивую просьбу возможно request_access. Составные запросы статус+следующий шаг требуют согласования правила. Результаты не означают качество на реальных данных или широкое обобщение. Модель не подтверждает заявки, не назначает права, не выдаёт номера/статусы сервиса. Request_access разрешает лишь рассмотрение подготовки черновика сервером, а отправка требует отдельного подтверждения.

На момент эксперимента проверены отдельный вызов и save/reload. Интеграция и команды текущей версии описаны в [README](../README.md).
