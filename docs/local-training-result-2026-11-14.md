# Результат локального обучения 14 ноября

Отчёт Артемия о тренировочном прогоне. Пути к скриптам и снимкам обучения относятся к переданному ML-архиву. Интеграция в проект и запуск сервиса описаны в [README](../README.md).

На RTX 4060 Laptop 8 ГБ реально дообучена Qwen3-1.7B через LoRA. Аренда не использовалась. Выполнены 3 эпохи, 324 микрошагa и 81 обновление оптимизатора на 108 train-примерах. Полный запуск с исходной оценкой, обучением, сохранением, reload и последующими оценками занял 150,6 секунды в этом окружении; это измерение одного запуска, не обещание времени на другом ноутбуке.

Пиковое выделение PyTorch: 3,62 GiB, пиковый резерв: 4,26 GiB. Эти величины не включают всю память графического драйвера/рабочего стола. Исходные веса заморожены, изменился LoRA-адаптер. Оплата GPU: 0 рублей.

## Передать Артуру

Архив output/local-trained-2026-11-14.zip содержит adapter-final, код, отчёт и инструкции. Большая исходная база не включена: нужна Qwen3-1.7B той же ревизии, её можно скачать скриптом tools/download_base_model.py по инструкции docs/arthur-reproduce.md.

```python
from ml.predictor import LocalIntentRouter
router = LocalIntentRouter(
    '.models/qwen3-1.7b',
    'reports/train-local-2026-11-14/adapter-final',
    device='cuda',
)
result = router.predict({
    'message': 'что мне делать дальше?',
    'workflow_state': 'pending_approval',
    'actor_context': {'user_id': 'demo-intern', 'team_id': 'alpha', 'role': 'intern'},
})
```

Создавать router один раз и выполнять запросы последовательно. Без adapter_path будет вызвана исходная модель. На чужой машине проверить GPU/зависимости и этот пример; код не реализует HTTP/MCP, это зона интеграции Артура. Права и подтверждение по-прежнему проверяет backend.
