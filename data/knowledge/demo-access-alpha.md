# Доступ в пространство команды Alpha

Это синтетическая инструкция для учебного прототипа. Она не является регламентом Авито и не описывает настоящую корпоративную систему.

Стажёр Alpha может подготовить заявку на ресурс `team_space`. Бэкенд определяет пользователя и команду из проверенной учётной записи. До отправки нужно просмотреть черновик и подтвердить его актуальную версию на странице приложения.

Тестовую заявку рассматривает демонстрационная роль наставника. После создания заявки статус `pending_approval` означает ожидание согласования. Это ещё не выданный доступ. Пока заявка рассматривается, следующий шаг — изучить доступную вводную инструкцию команды или проверить статус позже.

Номер и статус заявки берутся из тестового сервиса. При временном сбое можно безопасно подтвердить отправку ещё раз. Инструкция доступна стажёрам команды Alpha.
